# SevaRoute frontend

Concept C-inspired civic service guide built with React + Vite + React Router.

## Run
```bash
npm install
npm run dev
```

## Notes
- The service catalogue is demo data in `src/data/tasks.js`.
- `src/services/taskService.js` and `src/services/aiService.js` are integration points for your backend/AI.
- Login/register are demo-only local interactions. Do not use real passwords.
- Checklist progress and theme preference are saved in localStorage.
- Government process details vary by jurisdiction; verify current requirements on official portals.
